# Pip and the Gloomshrooms

Light the dark one spore at a time. Hop a tiny firefly through a haunted mushroom forest before your glow goes out.

Controls: Left/Right to move, Space to jump. Play free on Ryft.

This folder is a trailer kit: see TRAILER.md for the cut, clips/ for real gameplay footage, stills/ for one frame per clip, art/ for the title screen.
